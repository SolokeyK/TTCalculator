# TTCalculator
TFT S14 Trait Tracker Calculator
 - Helps you find teams to activate "Trait Tracker" Augment in S14, especially useful when you have Wandering Trainer/Emblems at level 6.
 - To use a packed app, unzip TTCalculator.zip.
 - The app will create input cache under the same directory. Run a "Lvl 7" (~30s) with no emblem/champion selected for the most common situation and save future time.

云顶之弈 S14 羁绊追踪者计算器
 - 自动凑羁绊，尤其是桩子开局/多转职时，帮助6级早开。
 - 使用应用网页：解压缩TTCalculator.zip。
 - 应用会在同一文件夹下缓存。下载后以默认0输入运行“7级”（约30秒）来保留最常见的7级三套阵容，节省时间。
