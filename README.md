# TTCalculator
TFT S14 Trait Tracker Calculator
 - Helps you find team to activate Trait Tracker, especially useful when you have Wandering Trainer/Emblems at level 6.
 - The app will create input cache under the same directory. Run a "Lvl 7" with no emblem/champion selected for the most common situation and save future time.
 - To use a packed app, unzip TTCalculator.zip.
